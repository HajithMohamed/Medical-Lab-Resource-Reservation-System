BenchBook design reference

Target look for the Resource Reservation Management System. Rebuild these screens with Tailwind CSS and shadcn/ui using the same tokens. Data shown is the demo seed: today is Tuesday 13 October 2026 and the viewer is Kasun Silva (staff, Main Laboratory, Colombo).

3. Calendar, day view (the signature screen)

A bench sheet: resources across, time down, hours in tabular figures. Teal blocks are bookings (solid teal = yours), hatched amber is maintenance, a hatched grey column with a red hang tag is out of service. Hovering a free slot tints it; every free slot is a keyboard-focusable link to the booking form. The real grid shows 24 hours and opens scrolled to 07:00.
